隱私權政策

生效日期：2026 年 11 月 12 日

本政策說明「眠小魚聊天室」（以下稱「本程式」）與本網站如何處理資料。本程式是 YouTube 頻道「FinaShy眠小魚」直播時使用的程式，由頻道經營者（以下稱「我們」）在自己的電腦上執行。

簡單說：本程式只用唯讀權限讀取我們自己頻道直播的公開聊天室，讓眠小魚回應同學們的留言；資料留在我們自己的電腦上，不販售，也不提供給第三方。

1. 本程式使用 YouTube API 服務

本程式透過 YouTube API 服務（YouTube Data API v3）取得資料。使用本程式即表示同意受 YouTube 服務條款約束；Google 如何處理資料，請參考 Google 隱私權政策。本程式的其他使用規定請見使用條款。

2. 我們取得哪些資料

本程式只會以頻道經營者自己的 Google 帳戶授權，申請的權限只有 YouTube 唯讀（https://www.googleapis.com/auth/youtube.readonly）。用這個權限讀取：

  • 本頻道的基本資料（頻道名稱與頻道 ID），用來確認授權的是正確的頻道。
  • 本頻道正在進行的直播場次。
  • 這些直播的公開聊天室訊息：留言者的顯示名稱與頻道 ID、留言內容、留言時間；如果是超級留言（Super Chat），還有金額與訊息。

本程式不會讀取觀眾的 Google 帳戶、電子郵件或任何非公開資料。觀眾不需要登入或授權本程式。

3. 資料用來做什麼

  • 讓眠小魚在直播中看到留言並即時回應。
  • 統計聊天室裡的互動投票，例如模擬倉的 !buy、!sell、!hold 指令。
  • 記住常來的同學，讓她之後的直播能叫出你的名字、接著聊之前的話題。我們不記錄金額與敏感的私人資訊。
  • 把同學問了但她還不會的問題記下來，之後補充學習再回答。準備教材時，這些問題可能交給 Anthropic 的 Claude 協助整理；交出前會拿掉留言者的名稱與頻道 ID，只留下問題本身。

這些資料不會用於廣告、不會用來建立廣告側寫、不會販售，也不會用來開發、改進或訓練通用的 AI 或機器學習模型。

4. 保存與安全

  • 上述資料保存在頻道經營者自己的電腦上，不放在公開的地方。
  • 直播中的回應由我們電腦上執行的 AI 模型產生，直播時的留言不會送到雲端 AI 服務。
  • 從 YouTube 取得的聊天室資料（顯示名稱、頻道 ID、留言內容與時間），以及據此留下的筆記，最多保存 30 天：同學在 30 天內再次留言，會以最新的資料更新；沒有的話，到期自動刪除。
  • 授權產生的存取權杖只保存在本機，不公開，也不放進版本控制，保存到授權被撤銷為止。

5. 分享與揭露

除了第 3 節提到、已經拿掉名稱與頻道 ID 的問題內容之外，我們不會販售、出租或分享透過 Google API 取得的資料給第三方，法律要求的情況除外。請注意，聊天室留言本來就是 YouTube 上的公開內容；眠小魚在直播中念出或回應的內容，也會成為公開直播與錄影的一部分。

6. Google API 有限使用聲明

本程式對從 Google API 取得之資訊的使用與傳輸，將遵守 Google API 服務使用者資料政策，包括其中的「有限使用」要求。

7. 撤銷授權與刪除資料

  • 授權本程式的 Google 帳戶，可以隨時在 Google 帳戶的安全性設定撤銷本程式的存取權。撤銷後，我們會在 30 天內刪除透過該授權取得的資料。
  • 觀眾如果希望我們刪除眠小魚記住的、與你有關的內容，請透過下方的聯絡方式告訴我們你的 YouTube 顯示名稱或頻道，我們會盡快並在 7 天內刪除本機保存的、與你相關的資料。
  • 這只會刪除本程式在我們電腦上保存的資料，不會影響 YouTube 上的任何資料；要刪除你在 YouTube 上的留言，請直接在 YouTube 上操作。

8. 本網站

本網站放在 GitHub Pages 上，不使用 cookie、分析工具或廣告，也沒有第三方會在本網站或本程式中投放內容或廣告。GitHub 可能為了安全與維運記錄造訪者的 IP 位址，詳見 GitHub 隱私權聲明。本程式在我們自己的電腦上執行，不會在你的裝置上存放或讀取任何資訊。

9. 政策更新

政策如果有修改，我們會更新本頁內容並修改上方的生效日期。

10. 聯絡我們

對本政策有任何問題，或要求刪除與你有關的資料，請到 GitHub 問題回報頁留言告訴我們。
